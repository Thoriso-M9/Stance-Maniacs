# Stance-Maniacs
A multi-page website for Stance Maniacs, a South African car styling, custom-build, and automotive photography business. Built with semantic HTML5 and custom CSS3
Overview

Stance Maniacs is a fully responsive, multi-page website designed to represent a real-world small business. It covers the essentials a client-facing automotive brand would need: a striking video landing page, a home page with featured builds, an about page telling the brand's story, a portfolio gallery, and a working contact page with an embedded map and a validated inquiry form.

Pages
Page	Description
landingpage.html: Full-screen autoplay video intro with a slide-out navigation menu
index.html: Home page with a featured "collection" hero, highlighted builds, and "why choose us" section
about.html: Brand story, team/service breakdown, company values, achievements, and client testimonials
portfolio.html:	Image gallery of completed builds with hover overlays describing each car's specs
contact.html:	Contact details, an embedded Google Map, and a client inquiry form with HTML5 validation

Features
 - Responsive design — hamburger navigation for mobile, adaptive layouts across all pages
 - Video hero section on the landing page for strong first impressions
 - Portfolio gallery with hover-reveal details for each vehicle build
 - Embedded Google Map for business location
 - Client-side form validation (pattern matching, min/max length) on the contact form
 - Custom typography using Google Fonts (Oswald & Inter)
 - Consistent branding across all pages (logo, color palette, social links, footer)
Tech Stack
HTML5 — semantic markup across all pages
CSS3 — custom styling in style.css (no frameworks or libraries)
Google Fonts API
